# PicPay Backend Challenge

Este repositório contém a solução para o desafio backend proposto pelo [PicPay](https://github.com/PicPay/picpay-desafio-backend). A implementação busca seguir as melhores práticas de desenvolvimento, fornecendo um código limpo, escalável e de fácil manutenção.

---

## 📝 Descrição do Desafio

O objetivo do desafio é criar uma API para realizar transações financeiras entre usuários, seguindo os requisitos especificados no repositório oficial do desafio. A API deve incluir funcionalidades como:

- Cadastro de usuários.
- Consulta de saldo.
- Realização de transferências.
- Notificações de transações realizadas.

Para mais detalhes, acesse o repositório oficial do desafio: [PicPay Backend Challenge](https://github.com/PicPay/picpay-desafio-backend).
